# Security Policy / 安全策略

## Supported versions

Security fixes are applied to the latest commit on `main` while the project remains pre-1.0.

## Report a vulnerability

Please use GitHub's **private vulnerability reporting** for this repository. Do not open a public issue containing an exploit, a private record, personal data, credentials, or screenshots of sensitive material. Include the affected version, reproducible steps using synthetic data, impact, and a suggested mitigation when possible.

请使用 GitHub 的**私密漏洞报告**功能。不要在公开 Issue 中提交漏洞细节、真实个案、个人信息、凭据或敏感截图；复现材料必须使用合成数据。

## Sensitive-data incident

If personal data is accidentally committed or attached, stop sharing the link, revoke exposed credentials when applicable, and contact the repository maintainers through a private channel. Deleting the current file does not remove it from Git history, caches, forks, or notifications; assess history rewriting and downstream notification separately.

## Scope notes

The demo JSON history and HTML-note output are not encrypted and are disabled by default. This repository does not provide production authentication, authorization, key management, audit logging, encrypted storage, or regulatory compliance controls.
