# Changelog

All notable changes to this project are documented here. The format follows Keep a Changelog principles, and the project uses Semantic Versioning after the first tagged release.

## [Unreleased]

## [0.1.1] - 2026-09-15

### Fixed

- Restored the advertised Python 3.10 compatibility for UTC timestamps.

## [0.1.0] - 2026-09-15

### Added

- Privacy-conscious local desktop prototype with an explainable Chinese text-signal baseline.
- In-memory DOCX extraction with size and structure validation.
- Session-only history by default and separately opt-in local persistence.
- Escaped, printable HTML review notes with opt-in disk output.
- DOCX archive-expansion safeguards, strict demonstration metadata, atomic output, and publish-tree privacy auditing.
- Fully synthetic example, static design prototype, model card, data/ethics guide, and test suite.

### Removed from the publishable tree

- Patent application files, generated reports, temporary case documents, previous history, and case source material.
- Hard-coded demo credentials and unsupported accuracy or operational claims.
- Five-sample serialized random-forest artifacts and hard-coded PDF executable paths.
